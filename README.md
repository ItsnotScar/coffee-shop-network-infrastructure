# Coffee Shop Network Infrastructure Project
## Overview
A small-business network infrastructure project developed using Cisco Packet Tracer to understand how network devices, routing, and security work together in a real-world environment.

## Objectives
- Separate Office, POS, Guest Wi-Fi, and Network Management networks using VLANs.
- Configure inter-VLAN routing, DHCP, static routing, and NAT/PAT.
- Apply ACLs to restrict guest access to internal networks.
- Implement basic switch security measures.

## Technologies
- Cisco Packet Tracer
- VLANs and inter-VLAN routing
- DHCP and static routing
- NAT/PAT
- Extended ACLs
- PortFast and BPDU Guard

## Project Documentation
See the **Coffee Shop Network Infrastructure Project** report in this repository for the network design, configurations, verification tests, and troubleshooting documentation.

## Disclaimer
This project is a network simulation created for learning and portfolio purposes. It does not represent a production network deployment.
